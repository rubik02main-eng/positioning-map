# People Positioning Map

知り合いを「大切にしたい」と「大切にすべき」(どちらも1〜100)の2軸で整理し、
人同士の関係値強度(0〜100)を線で見る、感情の整理用の個人PWA。
データは端末のlocalStorageにのみ保存し、外部送信しない。

## 使い方
- `index.html` をHTTPS配信(GitHub Pagesなど)で開く
- スマホ・タブレットのブラウザで「ホーム画面に追加」するとアプリとして起動できる
- 設定画面から、強さの目安の編集と、全データのバックアップ(JSON)ができる

## 更新時の注意
- `index.html` などを変えたら `sw.js` の `VERSION` を上げる(キャッシュ更新のため)
- 保存は `index.html` 内の `persist()` / `restore()` に集約している(将来Supabaseへ差し替える入口)
- 配色は黒基調(OGAデザインシステムのオレンジはハイライトのみ)

## 仕様メモ
- 軌跡は1日ごとに1点(設定で1週間・1か月に変更可)。点を消すときは確認が出る
- 「日付で見る」でその日の位置のマップを閲覧できる(閲覧のみ。関係値強度・メモ・材料は現在の値)
- 関係がなくなった人は削除せずアーカイブする(画面上部から戻せる)
